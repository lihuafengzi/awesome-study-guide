## 本地开发

### 环境配置

使用 Conda 创建虚拟环境（推荐）：

```bash
# 创建环境
conda create -n study-guide python=3.11

# 激活环境
conda activate study-guide

# 安装依赖
pip install -r requirements.txt
```

或使用 venv：

```bash
# 创建环境
python -m venv venv

# 激活环境 (Windows)
venv\Scripts\activate

# 激活环境 (macOS/Linux)
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```

### 链接检测脚本

项目中包含 `check_links.py` 脚本，用于自动检测 README 中所有链接的可用性：

```bash
# 运行链接检测
python check_links.py
```

输出示例：
```
[检测] 网站连通性检测
[信息] 发现 100 个链接

[OK] [200] LeetCode       | https://leetcode.cn/
[OK] [200] MDN Web Docs   | https://developer.mozilla.org/
[FAIL] [404] 某失效链接    | http://example.com/

[统计] 检测结果
[正常] 98/100
[失败] 2/100
```

## 如何贡献

欢迎提交 PR 补充更多优质学习资源！

1. Fork 本仓库
2. 添加你的资源（请标注推荐指数 ⭐）
3. 运行 `python check_links.py` 验证链接
4. 提交 Pull Request

### 贡献标准

- 资源应为**免费**或**有免费内容**
- 优先收录**中文**或**有中文支持**的资源
- 重要资源请标注 ⭐⭐⭐⭐⭐ 推荐
